# 📊 SQL Practice & Preparation Repository

Welcome to my SQL practice log! This repository contains my daily SQL practice scripts, structured by official database language categories and advanced querying concepts.

---

## 🗂️ SQL Categories & Topics

### 1. DDL (Data Definition Language)
*Commands used to define and modify the database structure.*
* [ ] `CREATE` (Tables, Databases, Views)
* [ ] `ALTER` (Adding, dropping, or modifying columns & constraints)
* [ ] `DROP` (Deleting tables or databases)
* [ ] `TRUNCATE` (Clearing all data from a table quickly)

### 2. DML (Data Manipulation Language)
*Commands used to manage data stored inside tables.*
* [ ] `INSERT` (Adding new rows)
* [ ] `UPDATE` (Modifying existing rows)
* [ ] `DELETE` (Removing specific rows)

### 3. DQL (Data Query Language)
*Commands used to fetch and retrieve data.*
* [ ] `SELECT` queries and column aliasing
* [ ] Filtering data (`WHERE`, `AND`, `OR`, `NOT`, `IN`, `BETWEEN`, `LIKE`)
* [ ] Sorting and limiting results (`ORDER BY`, `LIMIT`, `OFFSET`)
* [ ] Removing duplicates (`DISTINCT`)

### 4. Constraints & Data Integrity
*Rules enforced on columns to ensure data accuracy.*
* [ ] `PRIMARY KEY` & `FOREIGN KEY`
* [ ] `UNIQUE` & `CHECK` constraints
* [ ] `NOT NULL` & `DEFAULT` values
* [ ] Using the explicit `CONSTRAINT` keyword and naming conventions

### 5. Joins & Multi-Table Operations
*Combining data from multiple related tables.*
* [ ] `INNER JOIN`
* [ ] `LEFT JOIN` & `RIGHT JOIN`
* [ ] `FULL OUTER JOIN` & `CROSS JOIN`
* [ ] `SELF JOIN`

### 6. Aggregations & Functions
*Summarizing and manipulating data values.*
* [ ] Aggregate functions (`COUNT`, `SUM`, `AVG`, `MIN`, `MAX`)
* [ ] Grouping data (`GROUP BY` and `HAVING`)
* [ ] String, Numeric, and Date functions
* [ ] Conditional logic (`CASE` statements)

### 7. Subqueries & Advanced Querying
*Writing complex, nested queries.*
* [ ] Single-row and Multi-row subqueries
* [ ] Correlated subqueries and `EXISTS`
* [ ] Set operations (`UNION`, `UNION ALL`, `INTERSECT`)

### 8. DCL & TCL (Control Languages)
*Managing permissions and database transactions.*
* [ ] **DCL (Data Control Language):** `GRANT`, `REVOKE`
* [ ] **TCL (Transaction Control Language):** `COMMIT`, `ROLLBACK`, `SAVEPOINT`

### 9. Database Optimization & Administration
*Improving performance and structure.*
* [ ] Indexes (`CREATE INDEX`, performance impact)
* [ ] Views (`CREATE VIEW`)
* [ ] Stored Procedures & Triggers
